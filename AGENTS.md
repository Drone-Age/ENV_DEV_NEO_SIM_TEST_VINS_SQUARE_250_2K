# Обов'язкові правила роботи

1. Кожна зміна виконується лише на підставі попередньо створеного та
   затвердженого Issue цього репозиторію.
2. Заголовок і весь опис Issue, плану, Pull Request, звіту та release evidence
   оформлюються українською мовою.
3. Репозиторій містить лише test case квадратного маршруту 250 м / 2 км. Він
   не реалізує VINS-NEO і не визначає універсальні функції SIM-середовища.
4. SIM truth або RTK/PPK використовується лише незалежним test oracle і не
   може бути входом estimator або Pose Graph.
5. Commit, Pull Request, report і release evidence посилаються на Issue.
6. Rosbag/MCAP вимкнено. Запис дозволяється лише після прямої директиви
   користувача для конкретного запуску.

Нормативна зміна: `Drone-Age/ENV_DEV_NEO_SIM_TEST_VINS_SQUARE_250_2K#1`.
Координація SIM1: `Drone-Age/ENV_DEV_NEO_SIM1#12`.
