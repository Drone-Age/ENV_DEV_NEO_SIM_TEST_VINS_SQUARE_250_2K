# Профілі майданчика реального польоту

`site profile` створюється окремо для затвердженого майданчика та містить
центр квадрата, home, heading, дозволені висоти, геозону, RTL, часову
синхронізацію і RTK/PPK policy. Шаблон навмисно має `approved: false`, тому не
може дозволити ARM.

Фактичні координати майданчика та reference-файли не комітяться без окремого
Issue і польотного дозволу.
